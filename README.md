# 🤖 AI Resume Screening System

An AI-powered Resume Screening Web Application that compares resumes with job descriptions, calculates Resume Match Score, ATS Score, detects missing skills, and provides resume improvement suggestions.

🌐 **Live Demo:**  
https://ai-resume-screening-system-3-qzqb.onrender.com/

---

## ✨ Features

- 📄 Upload Resume (PDF)
- 💼 Compare Resume with Job Description
- 📊 Resume Match Score
- 🎯 ATS Score Calculation
- ⭐ Resume Strength Analysis
- ✅ Matched Skills Detection
- ❌ Missing Skills Detection
- 💡 Resume Improvement Suggestions
- 📱 Responsive User Interface
- 🌐 Live Deployment on Render

# 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/gauravv-boop/AI-Resume-Screening-System.git
```

### Open Project

```bash
cd AI-Resume-Screening-System
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run the Application

```bash
python app.py
```

Open:

```
http://127.0.0.1:5000
```

# 🔍 How It Works

1. Upload Resume (PDF)
2. Enter Job Description
3. Extract Resume Text
4. Detect Skills
5. Compare Resume with Job Description
6. Calculate Resume Match Score
7. Calculate ATS Score
8. Display Matched & Missing Skills
9. Generate Resume Suggestions
